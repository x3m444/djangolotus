Manual de Utilizare — Cantina Lotus

Ghid complet pentru toate rolurile aplicației
{# ══ 1. Flux general ══ #}

1. Flux general al aplicației

Aplicația urmărește traseul complet al unei zile de cantină, de la planificare până la livrare:

ADMIN
  └─ Planifică meniu săptămânal (produse per zi)
  └─ Lansează loturi de producție (cantități: prânz / cină / eveniment)
  └─ Lansează comenzi pentru firmele cu contract

RECEPȚIE
  └─ Preia comenzi livrare de la clienți individuali
  └─ Selectează livrator + oră + metodă plată

BUCĂTĂRIE
  └─ Tab Gătire:   vede tot ce trebuie gătit azi și marchează ✅ Gata
  └─ Tab Buffer:   pre-ambalează porții pentru ghișeu (masă și pachet)
  └─ Tab Împachetare: ambalează comenzile recepției + pachete firme + loturi eveniment
  └─ Tab Stoc Nevândut: declară ce a rămas la finalul zilei
  └─ Tab Necesar:  lista ingredientelor necesare (export Excel)

GHIȘEU
  └─ Tab Bon Casă: servire clienți direct, din buffer
  └─ Tab Firme:    servire nominală angajați cu contract
  └─ Tab Special:  comenzi speciale trimise la bucătărie
  └─ Tab Raport:   situația zilei

LIVRATOR
  └─ Vede comenzile ambalate alocate lui
  └─ Marchează "Pe drum" și "Livrat"
  └─ Generează aviz de însoțire (Excel)
  └─ Raportează probleme la livrare

Statusurile unei comenzi de livrare

nou pregatit pedrum livrat sau anulat
{# ══ 2. Autentificare ══ #}

2. Autentificare și roluri

Accesul necesită autentificare cu username + parolă. Fiecare utilizator are un singur rol; meniurile se adaptează automat.

RolAcces
adminToate modulele: Admin, Recepție, Bucătărie, Ghișeu, Livrare
receptieCreare comenzi, căutare clienți, lista comenzi
bucatarieGătire, buffer, împachetare, stoc, necesar ingrediente
ghiseuBon casă, firme, special, raport
livratorPropria rută, avize de însoțire
Utilizatorii cu rol livrator trebuie asociați cu un livrator din sistem de către Admin (Utilizatori → Schimbă livratorul asociat). Altfel ecranul de livrare va apărea gol.
{# ══ 3. Admin ══ #}

3. Admin

Modulul Admin conține: Lansare, Planificare, Firme, Nomenclator, Ingrediente, Utilizatori, Rapoarte.

3.1 Planificare Săptămânală

Scop: Stabilești ce produse apar în meniu pentru fiecare zi.

Tip planComponente obligatorii
PrânzFelul 1 + Felul 2 Varianta A + Felul 2 Varianta B + Salată/Accesoriu
CinăFelul 2 principal + Salată
SandwichUnul sau mai mulți sandwichs

Pași:

  1. Navighezi la săptămâna dorită cu butoanele ← / →
  2. Dai click pe ziua din calendar
  3. Completezi câmpurile pentru Prânz, Cină sau Sandwich
  4. Apeși Salvează

Tabelul săptămânal de sub formular arată planificarea pe 7 zile dintr-o privire. Butonul 📥 Export Flyer Meniu generează un Excel formatat A4 pentru tipărire.

3.2 Lansare Producție

Scop: Spui bucătăriei câte porții să pregătească.

Tip lotCând se folosește
Lot PrânzMeniu zilnic de prânz — produsele din planificarea zilei
Lot CinăMeniu de seară
Lot EvenimentCatering, protocol, pomeni — produse libere din nomenclator

Cum lansezi Lot Prânz:

  1. Selectezi data cu navigatorul săptămânal
  2. Introduci cantitățile lângă fiecare produs din planul zilei (apar automat)
  3. Apeși 🚀 Lansează Lot Prânz

Lot Eveniment: selectezi produsele din nomenclator, completezi Descrierea evenimentului (obligatorie), alegi tipul de ridicare (La masă / La pachet) și lansezi.

Completare lot existent: butonul ➕ Completează de lângă un lot adaugă produse extra la acesta.

Anulare lot: butonul 🗑️ Anulează — lotul nu mai apare în bucătărie și nu se ia în calculul stocului.

Tabelul Stoc Zilnic afișează per produs: Lansat | Consumat | Rămas în timp real.

3.3 Firme cu Contract

Modulul Firme are 4 taburi: Gestiune, Lansare, Prezență, Raport.

Tab Gestiune

Tip firmăDescriere
Ghișeu (nominal)Angajații vin la ghișeu; servire nominală per persoană
Ghișeu + LivrarePrânzul se livrează; cina se ridică la ghișeu
Livrare fixăCantitate fixă livrată zilnic
Meniu SpecialMeniu construit manual, independent de planificarea zilei
  • Adaugă firmă — Nume, Tip contract, Tip firmă → Adaugă
  • Adaugă angajat — câmpul din cardul firmei → ➕
  • Concediu/Inactiv — butonul 🔴 → angajatul trece în Inactivi
  • Reactivare — butonul 🟢 din secțiunea Inactivi
La orice modificare a angajaților activi, rezervarea zilnică se actualizează automat.

Tab Lansare

Lansezi comanda de livrare pentru firmele cu tip Ghișeu+Livrare, Livrare fixă sau Meniu Special: selectezi firma, produsele, cantitățile, livratorl și ora.

Tab Prezență

Confirmați câți angajați vin azi. Rezervarea se auto-inițializează din numărul angajaților activi; poți corecta manual per firmă.

Tab Raport

Per firmă, per zi: angajat, produse servite, tip servire, oră. Export Excel cu câte un sheet per firmă.

3.4 Nomenclator

Scop: Gestionezi lista de produse disponibile în aplicație.

CategorieUtilizare
🥣 felul_1Planificare prânz/cină
🍖 felul_2Planificare prânz/cină
🥗 salatePlanificare prânz/cină
🥪 sandwichPlanificare sandwich
✨ specialComenzi speciale ghișeu
🍮 desertComenzi extra

Operații: Adaugă (Nume + Categorie + Preț), Editează inline, Șterge, Export Excel.

3.5 Ingrediente și Rețete

Catalogul de ingrediente conține Nume, Unitate de măsură (kg/l/buc/g/ml), Categorie.

Din Nomenclator → click pe un produs → Rețetă pentru a gestiona ingredientele per produs. Cantitățile se introduc în g sau ml și se salvează automat în kg sau l.

La Lansare Producție, necesarul de ingrediente (porții × rețetă) se calculează automat și apare în Tab Necesar din Bucătărie.

3.6 Utilizatori

Creare utilizator: Username + Parolă + Rol + (opțional) Livrator asociat. Operații: activare/dezactivare, resetare parolă, schimbare livrator asociat.

3.7 Rapoarte

TabConținut
ComenziRezumat pe zile + detaliu per comandă (status, sofer, plată, produse, timestamps)
ProducțiePer produs, per zi: lot intern/eveniment/firme/recepție, gătit, servit, livrat, pierderi, rămas
FirmePer firmă: porții ghișeu/livrare, total lei, detaliu expandabil
LivratoriPer șofer: nr. comenzi livrate, total cash încasat
PierderiPer produs: zile cu pierderi, total pierderi/nevândut/risipă, detaliu pe zile
{# ══ 4. Recepție ══ #}

4. Recepție

Toate comenzile din recepție sunt de tip livrare — câmpul tip comandă este setat automat.

4.1 Comandă Nouă

1. Client — cauți din lista derulantă sau completezi Nume + Telefon + Adresă pentru un client nou (se creează automat).

2. Produse — 3 taburi de selecție:

TabConținut
Meniu RapidButoane V1 și V2 cu câmpuri de cantitate — cel mai rapid pentru comenzi standard
Plan ZiProdusele planificate azi, grupate pe categorii
Toate ProduseleÎntreg nomenclatorul: sandwich, speciale, orice

Produsele adăugate apar în Coșul Comenzii (mereu vizibil la dreapta). Poți modifica sau elimina produse din coș.

3. Detalii livrare:

  • Livrator *(obligatoriu)* — selectezi din lista șoferilor activi
  • Ora livrare — interval 09:00–14:00 (câte 30 min) sau ⚡ URGENT
  • Adresă livrare — adresa exactă
  • Metodă plată — Cash / Card / Cantină / Factură
  • Observații — instrucțiuni speciale (etaj, interfon etc.)

4. Apeși ✅ Plasează Comanda → comanda intră cu status nou.

4.2 Lista Comenzi

Afișează comenzile din ziua curentă cu filtru pe status. Din detaliu comandă poți schimba statusul sau anula comanda (dacă nu e deja livrată).

{# ══ 5. Bucătărie ══ #}

5. Bucătărie

5.1 Tab Gătire

Scop: Urmărești ce trebuie gătit și marchezi progresul.

Ce apare în lista de gătire:

  • Loturi lansate de admin (prânz + cină + eveniment) — gătite în bulk
  • Produse din comenzile recepției care NU sunt în planul zilei — sandwich, speciale, orice produs din tab „Toate Produsele"
Produsele din planul zilei comandate prin recepție nu apar separat — sunt acoperite de lotul lansat. Bucătăria gătește o singură dată în bulk.

Per produs: bară de progres, buton ✅ Tot Gata (marchează toate liniile ca gatit), buton Reset pentru corecție.

5.2 Tab Buffer Pre-ambalare

Scop: Pre-ambalezi porții generice pe care ghișeul le distribuie rapid fără să construiască meniu individual.

CheieConținutTip
f1, f2v1, f2v2, salComponente individuale (felul 1, feluri 2, salată)Masă
v1, v2Meniu complet (F1 + F2 + Salată)Pachet
solo_f1, solo_f2v1, solo_f2v2Porții solo (felul 1 sau felul 2 + salată)Pachet

Introduci cantitatea lângă componenta dorită → ➕ Adaugă. Sistemul verifică automat că produsele sunt gătite și că nu depășești cantitatea disponibilă.

Metrici afișate: Cantitate | Distribuit | Disponibil

5.3 Tab Împachetare

Scop: Ambalezi comenzile individuale gata de expediat.

  • Comenzi Recepție — apar cu indicator gătite/total. Când toate produsele sunt gata → 📦 Ambalat → status pregatit → apare la livrator.
  • Pachete Firme — angajați pentru care ghișeul a ales „La pachet" → 📦 Ambalat → apare la ghișeu ca „Gata de ridicat".
  • Loturi Eveniment — loturi admin de tip eveniment → 📦 Pregătit → apare la ghișeu pentru distribuție.

5.4 Tab Stoc Nevândut

Scop: La finalul zilei declari ce a rămas.

Câmpurile Rămas sunt pre-completate automat (Gătit − Servit − Livrat). Ajustezi dacă e cazul, completezi opțional Pierderi, apeși 💾 Salvează. Declarația poate fi refăcută oricând în aceeași zi.

5.5 Tab Necesar Ingrediente

Lista ingredientelor necesare calculată automat la lansarea loturilor (porții × rețetă). Bifezi ✓ Primit per ingredient. Export Excel — listă formatată A4 pentru tipărire.

{# ══ 6. Ghișeu ══ #}

6. Ghișeu

6.1 Tab Bon Casă

Scop: Clientul a plătit la casă — confirmi ce a cumpărat și scazi din buffer.

Selectezi Prânz / Cină (toggle), alegi meniurile și cantitățile (disponibilul din buffer apare lângă fiecare opțiune), selectezi tipul de ridicare (La masă sau La pachet), apeși ✅ Servește. Istoricul ultimelor 30 serviri apare mai jos.

6.2 Tab Firme

Scop: Servești angajații firmelor cu contract zilnic, nominal per persoană.

Per angajat neservit: selectezi meniu (V1/V2/Solo), alegi tipul de ridicare:

  • 🍽️ La masă — angajatul mănâncă pe loc; buffer masă scade
  • 📦 La pachet — merge la bucătărie pentru ambalare; după ambalare apare „📦 Gata" la ghișeu

Din același ecran poți adăuga un angajat nou (câmpul din cardul firmei → ➕) și marca concediu (butonul 🔴 → Inactivi; 🟢 → reactivare).

6.3 Tab Special

Scop: Ghișeul trimite comenzi pentru produse speciale (categorie special) la bucătărie.

Selectezi produsele + cantitățile + tipul de ridicare → Trimite la bucătărie. Bucătăria ambalează, ghișeul vede „Gata" și marchează ✅ Servit.

{# ══ 7. Livrator ══ #}

7. Livrator

Ecranul filtrează automat comenzile alocate numelui tău.

SecțiuneStatusAcțiuni
De preluatpregatit🚚 Pe drum · 📄 Aviz Excel
Pe drumpedrum✅ Livrat · ⚠️ Problemă
Livratelivrat— (arhivă zilnică)

Bara de sus afișează: De preluat / Pe drum / Livrate / Total cash de încasat.

Aviz de însoțire (Excel) — generat conform formularului legal, include Furnizor, Cumpărător, produse cu prețuri fără/cu TVA (11%), număr aviz unic, semnătură șofer.

Raportare problemă — butonul ⚠️ revine comanda la nou și adaugă o notă în observații (ex: „absent la domiciliu").

{# ══ 8. Stoc ══ #}

8. Stoc — cum se calculează

LANSAT   = cantitățile din lotul intern (admin, prânz + cină, neAnulate)

CONSUMAT = comenzi recepție livrare (clienți reali, neAnulate)
         + serviri ghișeu bon casă
         + serviri ghișeu firme

RĂMAS = max(LANSAT − CONSUMAT, 0)
Loturile de eveniment au stoc propriu și nu intră în CONSUMAT al lotului de prânz — se gestionează separat la ghișeu.
Comenzile recepției și servirile de la ghișeu trag din același lot lansat.
Dacă nu s-a lansat nicio producție, stocul este 0 chiar dacă există comenzi.
Loturile pot fi lansate cu o zi înainte (sau oricâte zile înainte). Sistemul nu restricționează data.

  → Murături ×40 → ✅ Tot Gata

  → V1 pachet ×15 · V2 pachet ×10 · f1 masă ×20

10:45 BUCĂTĂRIE — Tab Împachetare
  → Comanda Popescu Ion: 2/2 gata → 📦 Ambalat
  → Comanda Ionescu Maria: 1/1 gata → 📦 Ambalat

11:00 GHIȘEU — Tab Firme
  → SC Exemplu SRL:
    Ion Popescu → V1 → La masă ✓
    Maria Ionescu → V2 → La pachet → (bucătărie ambalează) → 📦 Gata → ridicat

11:30 GHIȘEU — Tab Bon Casă
  → Clienți directi: V1 ×3 → La masă → Servește

12:30 LIVRATOR (Mihai)
  → Popescu Ion → 🚚 Pe drum → ✅ Livrat
  → Ionescu Maria → 🚚 Pe drum → ✅ Livrat

14:30 BUCĂTĂRIE — Tab Stoc Nevândut
  → Fasole: gătit=15, servit=5, livrat=2 → declară 8 nevândut

08:00 ADMIN — Lansare → Lot Eveniment
  → Sarmale ×50, Cozonac ×20
  → Descriere: "Parastas Marinescu 15 mai"
  → Tip ridicare: La pachet → Lansează

10:00 BUCĂTĂRIE — Tab Gătire
  → Sarmale ×50 → ✅ Tot Gata
  → Cozonac ×20 → ✅ Tot Gata

10:30 BUCĂTĂRIE — Tab Împachetare → Loturi Eveniment
  → Parastas Marinescu: 2/2 gata → 📦 Pregătit

11:00 GHIȘEU — Lotul apare ca pregătit
  → Buton Distribuit → status livrat

1. Recepție → Comandă Nouă
2. Câmpul Client — nu găsești clientul în bază
3. Completezi: Nume, Telefon, Adresă
4. Clientul se creează automat la plasarea comenzii
5. Adaugi produse → Coș → Plasează Comanda

Client cere un produs care nu e în planul zilei (ex: Plăcintă):

1. Ghișeu → Tab Special
2. Selectezi "Plăcintă" (categorie special) × 1
3. Tip: La masă → Trimite la bucătărie

4. Bucătărie → Tab Împachetare → Secțiunea Comenzi Speciale
   → Comanda #X → 📦 Gata

5. Ghișeu → Tab Special → "Gata!" apare → ✅ Servit

1. Livrator → Pe drum → comanda Popescu Ion
2. Nu răspunde nimeni → ⚠️ Problemă → „absent la domiciliu"
3. Comanda revine la status nou cu nota adăugată
4. Recepția vede nota și contactează clientul
5. Dacă se rezolvă: recepția schimbă statusul înapoi la pregatit
